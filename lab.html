Претенденты — Противники без имени, рождённые из словаря Правил. Каждый держит Экзамен: по матчу против каждого выбранного Противника, до пяти минут. Оценка — урон по чужой Цитадели минус урон по своей и бонус за победу. Два лучших переходят в следующее Поколение без изменений, остальные — их дети: родители выбираются турниром из трёх, скрещиваются блоками и мутируют.
