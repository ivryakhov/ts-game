# Neon Arcana

Одиночная браузерная стратегия в реальном времени. Перед матчем игрок
программирует Поведение каждого типа Юнита набором Правил «Условие → Действие»;
во время матча он только распоряжается Эфиром. Юниты неуправляемы — всё, что
они делают, продиктовано Правилами.

## Команды

```bash
npm run dev        # сервер разработки
npm test           # тесты
npm run typecheck  # проверка типов
npm run build      # сборка
```

## Устройство

`src/sim` — ядро симуляции: не знает о браузере, запускается в Node, полностью
детерминировано по Сиду. Единственная точка входа и единственный сейм для
тестов — `runMatch`. `tests` — тесты на уровне матча, а не отдельных классов.
Отрисовка появится отдельным модулем в тикете 02; она будет читать снимок
состояния и не сможет его изменить.
