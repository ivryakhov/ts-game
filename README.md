# Neon Arcana

Одиночная браузерная стратегия в реальном времени. Перед матчем игрок
программирует Поведение каждого типа Юнита набором Правил «Условие → Действие»;
во время матча он только распоряжается Эфиром. Юниты неуправляемы — всё, что
они делают, продиктовано Правилами.

## Устройство

`src/sim` — ядро симуляции: не знает о браузере, запускается в Node, полностью
детерминировано по Сиду. Наружу смотрят два входа: `runMatch` прогоняет матч
целиком — это единственный сейм для тестов и будущего Автопрогона, — а
`createMatch` идёт по одному Тику за раз, и на нём держится игра в браузере.
Второй — цикл над первым, поэтому разойтись они не могут.

`src/maps` — карты как данные. `src/render` — отрисовка: получает снимок мира
и не может его изменить. `tests` — тесты на уровне матча, а не отдельных
классов.
