## 📖 Описание

**Neon Arcana** — это сетевая браузерная стратегия в реальном времени для 2-4 игроков. Игроки управляют магическими башнями и отправляют боевых юнитов по светящимся энергетическим дорогам, чтобы уничтожить башни противников.

### Особенности

- ⚔️ Стратегия в реальном времени
- 🎨 Визуальный стиль Arcane-punk (магия + технологии)
- 👥 Мультиплеер на 2-4 игрока
- 🏰 Система башен и юнитов
- 💰 Экономика с добычей ресурсов
- 🛤️ Множество путей для атаки

## 🚀 Быстрый старт

### Требования

- Node.js 18+
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd ts-game

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Откройте http://localhost:3000 в браузере.

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `1` | Выбрать Разведчика |
| `2` | Выбрать Танка |
| `3` | Выбрать Стрелка |
| `4` | Выбрать Поддержку |
| `G` | Показать/скрыть сетку |
| `D` | Режим отладки |
| **Клик по дороге** | Отправить юнита |
