## Этап 1: Технический прототип ✅ ЗАВЕРШЁН

**Длительность:** 1-2 недели  
**Цель:** Проверить core gameplay без графики и сети  
**Статус:** ✅ Завершён

### 1.1 Настройка проекта ✅

- [x] Инициализация TypeScript проекта
- [x] Настройка сборщика (Vite)
- [x] Настройка HTML5 Canvas для рендеринга
- [x] Базовая структура файлов и папок
- [x] Настройка тестирования (Vitest)
- [ ] Настройка линтера и форматтера (ESLint, Prettier)

### 1.2 Базовые классы и архитектура ✅

- [x] `Game` — главный игровой класс
- [x] `GameLoop` — игровой цикл с фиксированным timestep
- [x] `Unit` — класс юнита с 4 типами
- [x] `Tower` — башня игрока (главная и вспомогательные)
- [x] `Road` — дорога между башнями с waypoints
- [x] `Entity` — базовый класс с компонентами (Health, Combat, Movement)
- [x] `CanvasRenderer` — рендеринг на Canvas 2D
- [x] `Vector2` — математика 2D векторов

### 1.3 Минимальный геймплей ✅

- [x] Карта с 2 башнями (левая и правая)
- [x] 4 типа юнитов (Scout, Tank, Ranger, Support)
- [x] 2 дороги между башнями (изогнутые)
- [x] Базовая боевая система (HP/DPS)
- [x] Управление: 1-4 выбор юнита, клик по дороге для отправки
- [x] Экономика: пассивный доход эфира
- [x] Таймер матча (15 минут)

### 1.4 Тестирование ✅

- [x] Unit-тесты для Vector2 (61 тест)
- [x] Unit-тесты для Entity и компонентов (58 тестов)
- [x] Unit-тесты для Tower (43 теста)
- [x] Unit-тесты для Unit (66 тестов)
- [x] Unit-тесты для Road (55 тестов)
- [x] Покрытие кода ~90%
- [ ] Локальный режим: 2 игрока на одном экране
- [ ] AI-болванка для тестирования

### Критерии завершения этапа 1 ✅

- ✅ Можно создать юнита
- ✅ Юнит движется по дороге
- ✅ Юниты сражаются при встрече
- ✅ Юнит атакует вражескую башню
- ✅ Башня может быть уничтожена
- ✅ **БОНУС:** Все 4 типа юнитов реализованы
- ✅ **БОНУС:** Система контр-пиков реализована
- ✅ **БОНУС:** 283 unit-теста
