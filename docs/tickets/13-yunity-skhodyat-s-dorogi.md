# 13 — Юниты сходят с Дороги

**Что построить:** Юниты перестают ездить по Дорогам как по рельсам. Заметив
врага — Юнита или чужую Цитадель, — Юнит сходит с Дороги, чтобы его бить,
а потом возвращается. Ближние бьют только вплотную и не бьют сквозь других.
Решение и его цена — в [ADR-0004](../adr/0004-roads-are-routes-not-rails.md).

**Блокируется:** 12 — Противник как набор Правил.

**Статус:** done

- [x] Положение Юнита — точка на поле; пройденная Дорога — проекция этой точки
- [x] Юнит видит врага в пределах Обзора и по Правилу «атаковать» идёт к нему, сходя с Дороги, в том числе к врагу у другой Дороги
- [x] Отбившись, Юнит возвращается на свою Дорогу и идёт по ней дальше
- [x] У Юнита есть тело: он не проходит сквозь своих и чужих и не заходит внутрь чужой Цитадели
- [x] Ближний бьёт только вплотную: и Юнита, и Цитадель; Стрелок — со своей дальности
- [x] Лимит Стычки упразднён: сколько ближних бьётся с одним врагом, решает место вокруг него
- [x] Идущие к стенам обступают Цитадель по кругу, а не упираются в спины осаждающих
- [x] Матч с одинаковыми Правилами на обеих Сторонах по-прежнему зеркален
- [x] Рендер рисует Юнитов по точке, а огонь со стен — кругом вокруг Цитадели

**Как сделано.** Куда идти, решает `src/sim/movement.ts`: вперёд — к точке
Дороги чуть впереди своей проекции, у стен — к ближайшему свободному месту
вокруг Цитадели; к врагу — вплотную; назад — по Дороге к своей Цитадели.
Как шагнуть, не пройдя сквозь других, — `src/sim/steering.ts`: прямо, иначе
следом за своим, иначе в обход, иначе протиснуться сквозь стоящих своих,
иначе вбок вдоль препятствия. Налезших друг на друга расталкивает
`src/sim/crowd.ts`. Цель и удар — `src/sim/skirmish.ts`.
