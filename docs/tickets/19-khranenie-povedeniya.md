# 19 — Хранение Поведения

**Что построить:** Правила игрока переживают перезапуск, выгружаются файлом
и загружаются из файла, а испорченное сохранение не ломает игру и не
теряется молча. Подробности — раздел «Хранение»
[спеки 0002](../specs/0002-podgotovka-i-redaktor-pravil.md).

**Блокируется:** 17 — Редактор Правил.

**Статус:** ready-for-agent · **Задача:** [ivryakhov/ts-game#11](https://github.com/ivryakhov/ts-game/issues/11)

- [ ] Поведение игрока сохраняется в браузере (`neon-arcana:behaviour`, формат `player.json` без Волн) после каждой правки, если черновик без ошибок
- [ ] При запуске берётся сохранение, а без него — `player.json`
- [ ] Сохранение, не прошедшее разбор: берётся `player.json`, показывается причина и кнопка «Скачать отвергнутый набор»
- [ ] Недоступное хранилище браузера не ломает игру: она работает как без сохранения
- [ ] «Скачать» отдаёт файл в формате `player.json`
- [ ] «Загрузить» после подтверждения заменяет все три типа; ошибку показывает с местом и текущие Правила не трогает; Волны в файле игрока отвергаются
- [ ] Проверено глазами: правка → перезагрузка страницы → правка на месте; выгрузка → загрузка того же файла
