# 08 — Три типа Юнитов

**Что построить:** у игрока появляется выбор состава — Разведчик, Танк
и Стрелок с разными характеристиками, ценами и ролями в Стычке.

**Блокируется:** 07 — Эфир и покупка Юнитов.

**Статус:** ready-for-agent

- [ ] Доступны Разведчик, Танк и Стрелок, различимые формой фигуры
- [ ] У каждого типа свои запас здоровья, урон, скорость, дальность и цена
- [ ] Стрелок атакует с дистанции, находясь позади союзников в Стычке
- [ ] Цена каждого типа видна в панели покупки
- [ ] Тест: Стрелок наносит урон, не вступая в ближнюю Стычку
- [ ] Тест: Танк выдерживает заметно больше урона, Разведчик доходит заметно быстрее
- [ ] Тест: армия из одного типа Юнитов не разрушает Цитадель быстрее смешанной при равной стоимости (перенесено из тикета 06)
