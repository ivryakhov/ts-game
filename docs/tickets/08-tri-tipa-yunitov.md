# 08 — Три типа Юнитов

**Что построить:** у игрока появляется выбор состава — Разведчик, Танк
и Стрелок с разными характеристиками, ценами и ролями в Стычке.

**Блокируется:** 07 — Эфир и покупка Юнитов.

**Статус:** ready-for-agent

- [x] Доступны Разведчик, Танк и Стрелок, различимые формой фигуры
- [x] У каждого типа свои запас здоровья, урон, скорость, дальность и цена
- [x] Стрелок атакует с дистанции, находясь позади союзников в Стычке
- [x] Цена каждого типа видна в панели покупки
- [x] Тест: Стрелок наносит урон, не вступая в ближнюю Стычку
- [x] Тест: Танк выдерживает заметно больше урона, Разведчик доходит заметно быстрее
- [x] Тест: армия из одного типа Юнитов не разрушает Цитадель быстрее смешанной
      при равной стоимости (перенесено из тикета 06).

      Закрыт ответной атакой Цитадели (радиус 110 вдоль Дороги) и уроном стен
      17 в секунду — по решению владельца проекта, выше 15 из концепта. Замер
      волной при цене 180 Эфира: девять Разведчиков гибнут все, связка из двух
      Танков и двух Стрелков берёт Цитадель. Одни Стрелки и одни Танки не берут.

      Окно узкое: при 20 в секунду не берёт никто, а остальные смешанные
      составы не берут уже при 17. Число временное — подбирать его
      Автопрогоном из спеки 0003.
