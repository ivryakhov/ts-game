# 33 — Пауза после каждого Поколения

**Что построить:** галочка «Пауза после каждого Поколения». Прогон
встаёт после Экзамена и отбора; переключатель «Поколение N · сдано» /
«Поколение N+1 · собрано» показывает Оценки и детей сдавшего и Рождения
собранного. Подробности — раздел «Пауза после Поколения»
[спеки 0005](../specs/0005-rodoslovnaya.md).

**Блокируется:** 32

**Статус:** ready-for-agent

- [ ] Галочка в настройках, меняется на ходу; последнее Поколение не встаёт
- [ ] На паузе — переключатель сданного и собранного Поколения; «Продолжить» сдаёт собранное
- [ ] Тесты (поддельный Worker): встаёт после отбора, собранное не сдано; «Продолжить» сдаёт его; снятая галочка больше не останавливает
- [ ] Проверено глазами: пройти пять Поколений по одному
