# 29 — Все ядра

**Что построить:** Экзамен идёт в пуле Worker'ов по числу ядер минус
одно. Результат не зависит от числа потоков. Подробности — раздел
«Потоки» [спеки 0004](../specs/0004-laboratoriya.md).

**Блокируется:** 28

**Статус:** ready-for-agent

- [ ] Пул Worker'ов, результаты собираются по номеру Претендента и Противника
- [ ] На странице видно число потоков и время Поколения
- [ ] Тест: пул с исполнителем в том же процессе даёт те же Поколения при одном и при четырёх потоках
- [ ] Проверено глазами: Поколение считается в несколько раз быстрее, чем в тикете 28
