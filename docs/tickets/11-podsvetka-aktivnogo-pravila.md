# 11 — Подсветка активного Правила

**Что построить:** игрок может отладить собственное Поведение — выделить
Юнита и увидеть, какое именно Правило тот исполняет прямо сейчас и какую
цель по нему выбрал. Без этого система Правил неиграбельна.

**Блокируется:** 10 — Полный словарь Правил.

**Статус:** ready-for-agent

- [x] Юнита можно выделить кликом
- [x] Показывается Поведение его типа целиком, списком Правил в порядке приоритета
- [x] Правило, исполняемое в текущий Тик, подсвечено
- [x] Видно, какую цель Юнит выбрал и каким Действием
- [x] Подсветка корректна и читаема на паузе
- [x] Выделение снимается повторным кликом или по клавише отмены
