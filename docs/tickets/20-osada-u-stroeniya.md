# 20 — Осада у строения, а не только у Цитадели

**Что построить:** подготовка к Обелискам без изменения поведения. Осада
сейчас знает только чужую Цитадель: её тело, места у стены по кругу, долю
урона и то, какое строение бьёт осаждающий. Тикет переводит всё это на
строение — центр, радиус тела, владелец, — а Цитадель пока остаётся
единственным строением. Демо-остановки нет, как у тикета 01: проверка —
все тесты и зеркальность проходят без правки ожиданий. Зачем —
«Последствия» [ADR-0006](../adr/0006-obelisk-is-taken-by-force-and-is-not-an-enemy.md) и «Размер модулей» [спеки 0003](../specs/0003-obeliski.md).

**Блокируется:** —

**Статус:** ready-for-agent · **Задача:** [ivryakhov/ts-game#19](https://github.com/ivryakhov/ts-game/issues/19)

- [ ] Тела, сквозь которые не пройти, берутся из списка строений, а не только из чужих Цитаделей
- [ ] Место у стены по кругу считается для любого строения по его центру и радиусу тела
- [ ] Осаждающий знает, какое строение он бьёт, и бьёт его с той же долей урона, что сейчас Цитадель
- [ ] Поведение не меняется: все тесты проходят без правки ожиданий, матч с одинаковыми Правилами зеркален
- [ ] Ни один файл не превышает ~300 строк
