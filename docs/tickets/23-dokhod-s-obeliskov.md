# 23 — Доход с Обелисков

**Что построить:** захват окупается: Сторона получает +1.5 Эфира в секунду
за каждый свой Обелиск, и панель Эфира это показывает. Подробности —
раздел «Доход» [спеки 0003](../specs/0003-obeliski.md).

**Блокируется:** 22 — Захват.

**Статус:** ready-for-agent · **Задача:** [ivryakhov/ts-game#22](https://github.com/ivryakhov/ts-game/issues/22)

- [ ] Каждый Тик Сторона получает базовый доход и +1.5/с за каждый свой Обелиск; число — в таблице баланса
- [ ] Снимок Эфира отдаёт полный доход в секунду; панель Эфира показывает его у обеих Сторон
- [ ] Тест: Сторона с Обелиском за минуту получает на 90 Эфира больше Стороны без него
- [ ] Тест: доход уходит вместе с Обелиском — после его захвата противником прибавка у прежнего владельца пропадает
- [ ] Проверено глазами: после захвата в панели 6.0/с вместо 4.5/с
