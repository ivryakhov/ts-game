# 09 — Интерпретатор Правил

**Что построить:** сердце замысла. Поведение каждого типа Юнита задаётся
файлом — упорядоченным списком Правил «Условие → Действие». Юнит каждый
Тик исполняет первое Правило, чьё Условие истинно. Правка файла и перезапуск
матча меняют поведение Юнитов, не трогая код.

**Блокируется:** 08 — Три типа Юнитов.

**Статус:** ready-for-agent

- [x] Поведение каждого типа Юнита загружается из файла как упорядоченный список Правил
- [x] Исполняется первое Правило, чьё Условие истинно
- [x] Работают Условия: всегда; моё HP ниже N процентов; враг в радиусе атаки
- [x] Работают Действия: идти вперёд; атаковать ближайшего; отступить по Дороге
- [x] Неизвестный ключ или значение вне допустимого диапазона отвергаются с указанием места ошибки
- [x] Тест: каждое Условие и каждое Действие наблюдаемо меняет исход матча
- [x] Тест: Правило выше по списку вытесняет нижнее, когда оба Условия истинны
- [x] Тест: Юнит с правилом отступления при низком HP выживает там, где Юнит без него погибает
