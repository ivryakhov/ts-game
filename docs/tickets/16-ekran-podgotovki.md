# 16 — Экран Подготовки

**Что построить:** игра открывается Подготовкой, а не матчем. Игрок видит
Поведение своих типов и противника, характеристики типов и Сид, начинает
матч кнопкой «Начать матч», а после итога переигрывает или возвращается.
Правил здесь ещё не правят — это тикет 17. Подробности — разделы «Ход игры»
и «Экран Подготовки» [спеки 0002](../specs/0002-podgotovka-i-redaktor-pravil.md).

**Статус:** done · **Задача:** [ivryakhov/ts-game#7](https://github.com/ivryakhov/ts-game/issues/7)

- [x] Игра открывается Подготовкой; матч создаётся по «Начать матч», а не при загрузке страницы
- [x] Вкладки Разведчик / Танк / Стрелок: Правила типа теми же словами, что в панели выделенного Юнита, и карточка характеристик (HP, урон в секунду, дальность, Обзор, скорость в секунду, цена, ближний или дальний)
- [x] Вкладка «Противник»: его Правила по типам, только чтение; Волны не показываются
- [x] Поле Сида; `?seed=` в адресе по-прежнему задаёт его
- [x] В матч уходит копия Поведения: оно не меняется до итога
- [x] Итог предлагает «Переиграть» (тот же Сид), «Изменить Правила» (Подготовка с тем же Сидом) и «Новый Сид»
- [x] Новый Сид выбирает интерфейс, а не симуляция; он виден и попадает в адрес
- [x] Отвергнутый файл Стороны виден на Подготовке с причиной
- [x] Проверено глазами: полный цикл Подготовка → матч → итог → Подготовка → матч

**Как сделано.** Экран — `src/ui/prep.ts` (разметка в `index.html`),
характеристики словами — `src/ui/stats-text.ts`, кнопки итога —
`src/ui/outcome.ts`. Сид читается и выбирается в `src/app/seed.ts`,
а в адрес пишется из `src/ui/address.ts`: в `src/app` браузер знают только
модули ввода. В `src/main.ts` две фазы: на Подготовке Тики не идут,
клавиши времени и выбора типа молчат, клик по Дороге не выпускает
Юнита; каждый старт создаёт новый матч с копиями Сторон. Кнопка
называется «Начать матч», а не «В бой»: «бой» — слово из «_Избегать_»
словаря. Темп сохраняется между матчами.
