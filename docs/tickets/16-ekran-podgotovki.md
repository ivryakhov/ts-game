# 16 — Экран Подготовки

**Что построить:** игра открывается Подготовкой, а не матчем. Игрок видит
Поведение своих типов и противника, характеристики типов и Сид, начинает
матч кнопкой «В бой», а после итога переигрывает или возвращается.
Правил здесь ещё не правят — это тикет 17. Подробности — разделы «Ход игры»
и «Экран Подготовки» [спеки 0002](../specs/0002-podgotovka-i-redaktor-pravil.md).

**Блокируется:** —

**Статус:** ready-for-agent

- [ ] Игра открывается Подготовкой; матч создаётся по «В бой», а не при загрузке страницы
- [ ] Вкладки Разведчик / Танк / Стрелок: Правила типа теми же словами, что в панели выделенного Юнита, и карточка характеристик (HP, урон в секунду, дальность, Обзор, скорость в секунду, цена, ближний или дальний)
- [ ] Вкладка «Противник»: его Правила по типам, только чтение; Волны не показываются
- [ ] Поле Сида; `?seed=` в адресе по-прежнему задаёт его
- [ ] В матч уходит копия Поведения: оно не меняется до итога
- [ ] Итог предлагает «Переиграть» (тот же Сид), «Изменить Правила» (Подготовка с тем же Сидом) и «Новый Сид»
- [ ] Новый Сид выбирает интерфейс, а не симуляция; он виден и попадает в адрес
- [ ] Отвергнутый файл Стороны виден на Подготовке с причиной
- [ ] Проверено глазами: полный цикл Подготовка → матч → итог → Подготовка → матч
