# 28 — Поколения: отбор, скрещивание, мутации

**Что построить:** эволюция. После Экзамена из Поколения получается
следующее: элита, турнир, скрещивание блоками, мутации. Строка
«Поколение 12 из 50 · лучший выигрывает 4 из 7 · Оценка 5 230» растёт
на глазах; «Пауза» и «Стоп». Подробности — разделы «Мутации»,
«Скрещивание», «Поколение» [спеки 0004](../specs/0004-laboratoriya.md).

**Блокируется:** 27

**Статус:** ready-for-agent · **Задача:** [ivryakhov/ts-game#54](https://github.com/ivryakhov/ts-game/issues/54)

- [ ] Мутации из списка спеки, каждая держит пределы
- [ ] Скрещивание блоками; элита 2; турнир из трёх; первое Поколение — «с нуля» или «от готовых»
- [ ] Число Поколений, «Старт», «Пауза», «Стоп»
- [ ] Тесты: десять тысяч мутаций проходят `opponentFromFile`; ребёнок собран из целых блоков родителей; элита без изменений; тот же Сид — те же три Поколения
- [ ] Тест: за 10 Поколений по 8 Претендентов против «Раша-лёгкого» находится его победитель
- [ ] Проверено глазами: 30 Поколений против всех семи, лучшая Оценка растёт
