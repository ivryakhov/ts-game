# 28 — Поколения: отбор, скрещивание, мутации

**Что построить:** эволюция. После Экзамена из Поколения получается
следующее: элита, турнир, скрещивание блоками, мутации. Строка
«Поколение 12 из 50 · лучший выигрывает 4 из 7 · Оценка 5 230» растёт
на глазах; «Пауза» и «Стоп». Подробности — разделы «Мутации»,
«Скрещивание», «Поколение» [спеки 0004](../specs/0004-laboratoriya.md).
