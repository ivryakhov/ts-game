# 12 — Противник как набор Правил

**Что построить:** вторая Сторона оживает. Её Поведение и экономическая
политика описываются тем же файлом, что и у игрока, — отдельного кода
искусственного интеллекта не существует. С этого момента играется полный
матч человек против противника.

**Блокируется:** 10 — Полный словарь Правил.

**Статус:** ready-for-agent

- [x] Поведение противника загружается из файла тем же форматом, что и у игрока
- [x] Экономическая политика противника описана декларативно: пороги накопления и предпочтения по типам Юнитов и Дорогам
- [x] Отдельного кода искусственного интеллекта не существует
- [x] Противник не получает скрытых преимуществ: ни бесплатного Эфира, ни знания, недоступного игроку
- [x] Играется полный матч до разрушения одной из Цитаделей
- [x] Тест: матч двух наборов Правил без участия человека завершается победителем

**Как сделано.** Экономика Стороны — список Волн в её файле, рядом с Правилами
(`src/behaviours/opponent.json`). Порог накопления — цена Волны: Сторона копит,
пока не хватит на всю Волну, и выпускает её разом, в заданном порядке.
Предпочтения по типам и Дорогам — состав и Дорога каждой Волны. Список
проходится по кругу. Файл игрока — тот же формат без Волн.

Волны не смотрят на поле и не знают чужого Эфира, поэтому противник
предсказуем и одинаков при любом Сиде. Реагирующий противник — вопрос уровней
сложности (этап 8 плана v1), а не этого тикета.
