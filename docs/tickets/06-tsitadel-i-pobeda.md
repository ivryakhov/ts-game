# 06 — Цитадель, урон по ней и победа

**Что построить:** дошедшие Юниты атакуют вражескую Цитадель, и матч
получает исход — разрушение Цитадели завершает партию с победителем.

**Блокируется:** 05 — Стычка и смерть.

**Статус:** ready-for-agent

- [ ] Дошедшие до вражеской Цитадели Юниты атакуют её
- [ ] Урон по Цитадели заметно ниже урона, который тот же Юнит наносит Юнитам
- [ ] Запас здоровья обеих Цитаделей виден на экране
- [ ] Урон по своей Цитадели вызывает вспышку экрана
- [ ] Разрушение Цитадели завершает матч с указанием победителя и длительности
- [ ] Тест: матч завершается победой, а не по лимиту Тиков
- [ ] Тест: армия из одного типа Юнитов не разрушает Цитадель быстрее смешанной при равной стоимости
