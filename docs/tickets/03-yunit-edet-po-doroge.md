# 03 — Юнит едет по Дороге

**Что построить:** Юнит появляется у своей Цитадели, проходит выбранную
Дорогу до вражеской и там исчезает. Движение плавное, над Юнитом виден
запас здоровья. Состав и расписание появления пока заданы жёстко.

**Блокируется:** 02 — Карта на экране.

**Статус:** ready-for-agent

- [x] Юнит проходит Дорогу от своей Цитадели до вражеской и исчезает
- [x] Картинка обновляется чаще Тика и интерполирует положение между Тиками
- [x] Над Юнитом виден health bar
- [x] Юнит окрашен в цвет своей Стороны
- [x] Длинные Дороги проходятся заметно дольше короткой
- [x] Тест: Юнит достигает конца Дороги за предсказуемое число Тиков
- [x] Тест: два прогона с одним Сидом дают идентичный результат
