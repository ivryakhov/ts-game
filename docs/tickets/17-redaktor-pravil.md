# 17 — Редактор Правил

**Что построить:** главная часть этапа 6 — Правила своих типов правятся
на Подготовке. Строка собирается из выпадающих списков, так что
синтаксической ошибки не сделать. Подробности — раздел «Редактор»
[спеки 0002](../specs/0002-podgotovka-i-redaktor-pravil.md).

**Блокируется:** 14 — «И» в Правилах; 16 — Экран Подготовки.

**Статус:** ready-for-agent · **Задача:** [ivryakhov/ts-game#9](https://github.com/ivryakhov/ts-game/issues/9)

- [ ] На вкладке своего типа Правила — строки «если [Условие ▾][N] + и … — [Действие ▾]»; у «бить тип» ещё [тип ▾]
- [ ] У каждой строки ↑ ↓ ✕; «+ Правило» добавляет новое над последним
- [ ] «+ и» добавляет Условие, пока их меньше трёх; ✕ у Условия убирает его, пока их больше одного
- [ ] Последняя строка «иначе — [Действие ▾]» закреплена: не удаляется, не двигается, её Условие не меняется
- [ ] Выбранное Условие получает число по умолчанию: HP ниже 30%, своих рядом меньше 2, врагов в Стычке больше 2
- [ ] Число вне допустимого отмечается на месте текстом разбора; «В бой» недоступна, пока ошибка есть
- [ ] Матч получает ровно то, что на экране, и только после того же разбора, что у файла
- [ ] «Изменить Правила» после итога возвращает к тому же черновику
- [ ] Ограничения на число Правил и перетаскивания нет
- [ ] Ни один файл не превышает ~300 строк
- [ ] Проверено глазами: собрать «Осторожного» руками и увидеть его в матче в панели выделенного Юнита
