# 17 — Редактор Правил

**Что построить:** главная часть этапа 6 — Правила своих типов правятся
на Подготовке. Строка собирается из выпадающих списков, так что
синтаксической ошибки не сделать. Подробности — раздел «Редактор»
[спеки 0002](../specs/0002-podgotovka-i-redaktor-pravil.md).

**Блокируется:** 14 — «И» в Правилах; 16 — Экран Подготовки.

**Статус:** done · **Задача:** [ivryakhov/ts-game#9](https://github.com/ivryakhov/ts-game/issues/9)

- [x] На вкладке своего типа Правила — строки «если [Условие ▾][N] + и … — [Действие ▾]»; у «бить тип» ещё [тип ▾]
- [x] У каждой строки ↑ ↓ ✕; «+ Правило» добавляет новое над последним
- [x] «+ и» добавляет Условие, пока их меньше трёх; ✕ у Условия убирает его, пока их больше одного
- [x] Последняя строка «иначе — [Действие ▾]» закреплена: не удаляется, не двигается, её Условие не меняется
- [x] Выбранное Условие получает число по умолчанию: HP ниже 30%, своих рядом меньше 2, врагов в Стычке больше 2
- [x] Число вне допустимого отмечается на месте текстом разбора; «Начать матч» недоступна, пока ошибка есть
- [x] Матч получает ровно то, что на экране, и только после того же разбора, что у файла
- [x] «Изменить Правила» после итога возвращает к тому же черновику
- [x] Ограничения на число Правил и перетаскивания нет
- [x] Ни один файл не превышает ~300 строк
- [x] Проверено глазами: собрать «Осторожного» руками и увидеть его в матче в панели выделенного Юнита
