# 07 — Эфир и покупка Юнитов

**Что построить:** игрок впервые принимает решения. Эфир накапливается
пассивно, игрок тратит его на Юнитов и выбирает Дорогу, по которой они
уходят. Всё это работает и на паузе.

**Блокируется:** 06 — Цитадель, урон по ней и победа.

**Статус:** ready-for-agent

- [ ] Эфир начисляется пассивно; текущий запас и доход в секунду видны на экране
- [ ] Игрок покупает Юнита и выбирает одну из трёх Дорог для него
- [ ] Покупка при нехватке Эфира отклоняется с понятной обратной связью
- [ ] Покупку можно совершить на паузе
- [ ] Действие игрока привязано к номеру Тика, а не к реальному времени
- [ ] Тест: одинаковый список действий по Тикам даёт идентичный матч на любой скорости
- [ ] Тест: покупка при нехватке Эфира не создаёт Юнита и не списывает Эфир
