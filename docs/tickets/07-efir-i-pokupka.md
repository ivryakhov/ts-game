# 07 — Эфир и покупка Юнитов

**Что построить:** игрок впервые принимает решения. Эфир накапливается
пассивно, игрок тратит его на Юнитов и выбирает Дорогу, по которой они
уходят. Всё это работает и на паузе.

**Блокируется:** 06 — Цитадель, урон по ней и победа.

**Статус:** ready-for-agent

- [x] Эфир начисляется пассивно; текущий запас и доход в секунду видны на экране
- [x] Игрок покупает Юнита и выбирает одну из трёх Дорог для него
- [x] Покупка при нехватке Эфира отклоняется с понятной обратной связью
- [x] Покупку можно совершить на паузе
- [x] Действие игрока привязано к номеру Тика, а не к реальному времени
- [x] Тест: одинаковый список действий по Тикам даёт идентичный матч на любой скорости
- [x] Тест: покупка при нехватке Эфира не создаёт Юнита и не списывает Эфир
