# 05 — Стычка и смерть

**Что построить:** Юниты двух Сторон, встретившись на Дороге, останавливаются
и вступают в Стычку. Бьются не все сразу — число одновременных участников
ограничено, остальные ждут своей очереди. Раненые вспыхивают, погибшие
исчезают.

**Блокируется:** 03 — Юнит едет по Дороге.

**Внимание:** это тот этап, на котором была заброшена январская попытка —
баг «Юниты зависают в бою». Детерминизм и воспроизводимость здесь важнее
скорости.

**Статус:** ready-for-agent

- [ ] Встретив врага, Юнит останавливается и вступает в Стычку
- [ ] Одновременно атакует ограниченное число Юнитов с каждой стороны
- [ ] Ожидающие очереди Юниты визуально отличимы от бьющихся
- [ ] Место выбывшего занимается детерминированно — по времени вступления, а не случайно
- [ ] Получая урон, Юнит вспыхивает; погибая — схлопывается и исчезает
- [ ] Тест: трое против одного — побеждает сторона из троих, лимит Стычки не превышается
- [ ] Тест: Стычка всегда завершается, ни один Юнит не застревает в бою навсегда
- [ ] Тест: два прогона одной Стычки с одним Сидом идентичны
