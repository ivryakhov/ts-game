# 10 — Полный словарь Правил

**Что построить:** словарь дорастает до размера, на котором Поведение
становится выразительным: Юнит может дожидаться подкрепления, избегать
заведомо проигранной Стычки и фокусировать цель по выбору игрока.

**Блокируется:** 09 — Интерпретатор Правил.

**Статус:** ready-for-agent

- [x] Добавлены Условия: союзников рядом меньше или больше N; врагов в Стычке больше N; враг впереди на Дороге; вражеская Цитадель в радиусе
- [x] Добавлены Действия: атаковать слабейшего; атаковать самого опасного; атаковать заданный тип; остановиться и ждать
- [x] Скрытых модификаторов урона нет — исход Стычки объясним Правилами и характеристиками
- [x] Тест: для каждого нового Условия и Действия есть ситуация, где оно меняет исход
- [x] Тест: Поведение «ждать, пока рядом меньше трёх союзников» приводит к накоплению группы перед атакой
