# 26 — Показательный матч: Противник против Противника

**Что построить:** на Подготовке выбор «За меня играет: я / Противник».
Выбран Противник — Сторона A берёт его Правила и Волны, клики по Дороге
молчат, панель пишет «Показательный матч». Подробности — раздел
«Показательный матч» [спеки 0004](../specs/0004-laboratoriya.md).

**Блокируется:** —
