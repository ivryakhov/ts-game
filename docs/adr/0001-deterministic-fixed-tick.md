# Симуляция детерминирована и идёт фиксированным Тиком

Прошлый прототип (январь 2026) утонул в баге «Юниты зависают во время боя с
Нейтралами»: четыре коммита подряд пытались его чинить, и проект был заброшен.
Баг был невоспроизводим, потому что логика выполнялась на плавающем `deltaTime`
и смешивалась с рендером.

Поэтому вся игровая логика выполняется только внутри Тика фиксированной
длительности, вся случайность берётся из генератора, инициализированного Сидом,
а рендер лишь интерполирует состояние между Тиками и не может его изменить.
Одинаковый Сид плюс одинаковая последовательность действий игрока дают
побитово одинаковый матч.

## Последствия

- Любой баг воспроизводится Сидом и списком действий — отладка перестаёт быть гаданием.
- Автопрогон сотен матчей бот-против-бота для балансировки становится возможен:
  симуляция запускается без рендера на максимальной скорости.
- Пауза и ускорение ×2/×4/×8 достаются бесплатно — это просто число Тиков за кадр.
- Цена: во всей игровой логике запрещены `Math.random()`, `Date.now()` и любое
  чтение реального времени. Числа с плавающей точкой допустимы только потому,
  что игра одиночная и кросс-машинный детерминизм не требуется.
- Если когда-нибудь появится сетевой режим, lockstep-модель уже готова.
